# Project Memory

This file records durable project context that should not live only in chat.

## Collaboration Rules

- Key information from our conversations should be recorded locally when it matters for future work, especially decisions, user preferences, architecture constraints, and project direction.
- This AI agent project is in an early stage. The goal is to build a personal agent system tailored to the user's own workflow and needs, not a generic template.
- The user wants Codex to generate and maintain relevant skills plus project background descriptions, and to collaborate on building the project from start to finish.
- Chinese records are required. Important project memory, user preferences, decisions, and background notes should be recorded in the Chinese memory file first, not only in English.
- Multilingual content should be maintained in separate language files instead of mixing Chinese and English in one long-term document.

## Project Documents

- `PROJECT_MEMORY.md` is the project memory index.
- `PROJECT_MEMORY.zh-CN.md` is the Chinese project memory.
- `PROJECT_MEMORY.en-US.md` is the English project memory.
- `docs/PROJECT_BACKGROUND.md` is the project background index.
- `docs/PROJECT_BACKGROUND.zh-CN.md` is the Chinese project background.
- `docs/PROJECT_BACKGROUND.en-US.md` is the English project background.
- `skills/personal-agent-project/` contains the project-specific Codex skill draft.
