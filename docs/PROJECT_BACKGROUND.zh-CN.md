# XiaoMiCode 项目背景

## 项目意图

XiaoMiCode 是一个早期 AI Agent 项目。它的目标不是套用通用模板，而是逐步搭建一个贴合用户个人工作流、偏好和长期需求的 Agent 系统。

这个项目会通过大量对话和多轮实现逐渐成形。重要上下文必须记录到本地文件中，尤其是项目决策、用户偏好、架构约束、开放问题和阶段性方向，避免只存在聊天历史里。

## 协作原则

- 把这个项目当作一个从想法到可用系统的长期协作。
- 当信息会影响未来工作时，把它记录到本地，包括架构选择、用户偏好、约束、命名约定、工作流和开放问题。
- 重要上下文优先写入中文文档；需要英文时，维护对应英文文件。
- 多语言内容按文件拆分维护，避免在同一份长期文档里中英混排。
- 项目早期优先采用小步、清晰、可检查的方式推进。
- 先服务用户真实工作方式，再考虑抽象成更通用的框架能力。
- 在项目文件中保留清晰的决策轨迹。

## 初始产品方向

项目预计会探索并最终实现一个面向工作协作体的个人 AI Agent。它不是单一助手，而是以“项目”作为主要输入和输出口，由项目角色协调多个专业工种角色完成工作。

初始角色可能包括：

- 项目。
- 产品。
- 技术。
- 开发。
- 测试。

未来可扩展角色包括设计、视频、音频、运营、数据等。

系统可能包含以下能力：

- 工具调用和本地自动化。
- 项目记忆和对话记忆。
- 任务规划与执行循环。
- 面向重复工作流的 Skills 或插件机制。
- 多角色协作、角色分工、任务交接和产出汇总。
- 可选的交互界面，例如 CLI、Web、桌面端或消息集成。
- 模型和服务商接入，可能包括 OpenAI APIs。

这些只是起始方向，不是最终需求。后续应随着用户明确优先级继续调整。
